What This Is

A simple task manager built as Project 1 of a structured MERN full-stack development course. It allows adding tasks, marking them complete, and deleting them, with data persisted in the browser using localStorage.

Technologies Used

  • HTML5 — semantic structure
  • CSS3 — Flexbox layout, responsive design
  • Vanilla JavaScript — DOM manipulation, event delegation, localStorage

What I Learned

This project reinforced how the DOM can be built and modified entirely through JavaScript, how event delegation allows handling clicks on elements that don't exist yet at page load, and how localStorage can persist data across page reloads without a backend server.

What's Next

Later in this course, this same task manager concept will be rebuilt as a full-stack application, replacing localStorage with a real database (MongoDB) and a backend API (Express/Node.js).
