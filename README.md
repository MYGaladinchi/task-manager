# Task Manager

A simple task management app built with vanilla HTML, CSS, and JavaScript - no frameworks, no build tools.

## Features

- Add new tasks via a form
- Mark tasks as complete (click the task text)
- Delete tasks
- Tasks persist across page reloads using localStorage

## Technologies Used

- HTML5 (semantic structure)
- CSS3 (Flexbox layout, responsive design)
- Vanilla JavaScript (DOM manipulation, event delegation, localStorage)

## How to Run

Since this is a static site with no build process, simply open index.html in a browser, or serve the folder locally with: npx serve

Then open the printed local URL in your browser.

## Project Context

This is Project 1 of a structured MERN full-stack development course, focused on demonstrating DOM manipulation and event handling fundamentals before moving into backend development with Node.js, Express, and MongoDB, and later React.
